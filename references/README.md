# Nguồn tham khảo ngoài dự án

`retail-management/` là project quản lý cửa hàng bán lẻ được dùng để tham khảo cách tổ chức repository, tài liệu, backlog và quy trình Git.

Không sao chép nguyên:

- Nghiệp vụ bán hàng/đào tạo.
- PostgreSQL, Flyway hoặc contract riêng của project bán lẻ.
- Tên thành viên, trạng thái sprint, PR và bằng chứng kiểm thử của project khác.

Quyết định hiện hành của hệ thống kho nằm trong `docs/` và `AGENTS.md` ở root.
